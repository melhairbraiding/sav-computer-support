Admin password

For security, the admin password no longer lives in this panel or in the site's database — it's set as the ADMIN_PASSWORD environment variable in Netlify (same place as BLOBS_SITE_ID and BLOBS_API_TOKEN). This means it's never sent to or stored in your browser, and can't be read by inspecting the site's code.

To change it: Netlify dashboard → this site → Site settings → Environment variables → edit ADMIN_PASSWORD → trigger a redeploy for it to take effect.
